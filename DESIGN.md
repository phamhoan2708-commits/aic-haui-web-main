# AIC visual contract

## Typography

- Use self-hosted Be Vietnam Pro everywhere.
- Mobile body: 14px / 24px.
- Mobile card: 17px / 25px / 700.
- Mobile section: 22px / 31px / 700.
- Mobile major: 30px / 42px / 700.
- Mobile hero: 36px / 44px / 700.
- Desktop body: 14px / 26px.
- Desktop card: 18px / 27px / 700.
- Desktop section: 23px / 34px / 700.
- Desktop major: 35px / 52px / 700.
- Desktop hero: 56px / 64px / 700.

## Header

- Desktop header: 72px brand tier + 48px navigation tier.
- Mobile header is fixed at 64px.

## Visual direction

- Preserve AIC navy, blue, and gold; rounded surfaces; video hero; and whitespace.
- Equivalent heading levels use consistent capitalization and typography.
- Missing factual media stays a neutral frame and never represents itself as official.

## Motion and accessibility

- Use lightweight reveals, hero phrase rotation, and clipped staff portrait zoom.
- Staff portrait scale is exactly 1.2 on hover.
- Reduced motion disables nonessential motion.
